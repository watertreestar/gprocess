# M12 设计：文件占用 Agent 归因

## 候选定位

用户只需提供至少两个字符的文件名或目录名，默认在 USERPROFILE 下按名称大小写不敏感包含匹配，最多遍历 20,000 个条目并返回 80 个候选；触及上限提示结果不完整。文件夹可进入并浏览其直接子项，也可在目录内继续搜索；不追踪符号链接、跳过不可读取目录，不扫描其他磁盘。搜索放在阻塞线程中执行，避免卡住 Tauri 异步运行时。此方式不是 Windows 全盘索引，搜索不到不等于文件不存在。

## 查询与可信度

继续使用 Windows Restart Manager 查询单个普通文件；不将零结果当作“无人占用”。路径在调用前检查存在且为普通文件。RM 返回的 PID 与启动时间对照 sysinfo 进程启动时间，以秒精度核实，避免 PID 复用时关联错误进程；核实失败时保留 RM 行信息，但不标 Agent，也不开放进程操作。前端以 PID + 启动时间与最新快照匹配，防止展示后的 PID 复用；快照尚未同步到该进程或进程已退出时隐藏归因标签并禁用操作。

## 归因规则

先检查占用进程的精确可执行名，再检查 M9 从 runtime 命令行提取的脚本标记；命中展示“Agent 占用”与信号。若自身未命中，则检查存活且启动早于子进程的父进程，再检查父身份记忆中同一子进程启动时间的历史记录；命中仅展示“Agent 关联”。通用 runtime 名称如 node/python 和普通构建工具不作为 Agent 证据。未命中不作否定判断。

当前识别名单：Claude Code、Codex、Cursor、Windsurf、Qoder、OpenCode、Aider、Agent Browser。名单采用精确标识，不推断任意命令行内容或文件所有权。父进程线索只表明来源关联，不能证明父进程打开了该文件。

## 验证边界

单测覆盖 RM 自持句柄、关闭后空结果、Agent 精确匹配、通用运行时非命中、父进程归因及 PID 复用防护。桌面端仍需以实际已知占用文件验收：Restart Manager 对高权限、跨用户和部分句柄不保证完整可见，因此空结果不用于证明文件可删除。
