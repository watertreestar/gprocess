# M11 自动更新检查

## 目标

应用启动后自动静默检查 GitHub Releases 上的新版本；发现新版本时弹窗提示（含版本说明），用户确认后下载安装并自动重启；支持「跳过此版本」持久化，避免重复打扰。设置页保留手动「检查更新」入口，复用同一弹窗流程。

## 范围

- 前端实现：`@tauri-apps/plugin-updater` JS API（依赖已存在，插件已在 `lib.rs` 初始化，pubkey / endpoints 已配置）
- `Settings` 增加 `skippedVersion` 字段（settings.json 为前端自有 schema，后端原子写已支持，无后端改动）
- 排除：定时轮询、静默后台下载、自动更新开关、发布签名自动化

## 验收标准

1. 启动后延迟约 8 秒静默检查一次；无新版本、检查失败、开发环境均不打扰用户
2. 发现新版本且非跳过版本时，弹窗显示版本号与更新说明，提供「跳过此版本 / 稍后 / 下载并安装」
3. 下载安装显示进度（contentLength 缺失时显示不确定进度），完成后自动重启应用
4. 跳过版本写入 settings.json，下次启动不再提示该版本；出现更新版本后恢复提示
5. 设置页「检查更新」手动入口忽略跳过状态直接弹窗；无更新 / 检查失败时 toast 反馈
6. `npm run build`（tsc + vite）通过；dev 启动行为核验不打扰
