# M4 常驻与自动化

## 目标

把 gprocess 从"用完即走的工具"升级为"常驻型管理面板"：托盘常驻、开机自启、自动更新、主动通知，并增强单进程的可观测性（资源曲线）。

## 范围

**包含**

- 系统托盘：关窗最小化到托盘，托盘菜单「显示主面板 / 退出」
- 进程资源曲线：详情侧栏展示选中进程近 60 秒 CPU / 内存迷你折线（前端采样）
- 开机自启：`tauri-plugin-autostart`，设置页开关
- 自动更新（GitHub Release）：`tauri-plugin-updater`，设置页"检查更新"，下载安装后重启
- 系统通知（Windows 原生 toast）：超高资源占用 + 长时间孤儿进程，带冷却防刷屏；设置页开关与阈值

**不包含**

- 应用内横幅通知（如系统通知不够用再评估）
- 自动更新的 CI/CD 发布流水线（先走手动发版）
- 批量结束、快照 diff 高亮（候选列表保留）

## 验收标准

1. 关窗后进程仍在托盘，点托盘图标恢复窗口，菜单「退出」完全退出。
2. 选中进程后侧栏显示近 60 秒 CPU/内存折线，随快照滚动更新。
3. 设置页开启「开机自启」后，注册表 Run 键写入；重启系统验证（人工）。
4. 设置页"检查更新"能正确报告"已是最新"；新版本发布到 GitHub Release 后可下载并自动安装（发版时验证）。
5. 构造高 CPU 进程（如死循环脚本）触发系统通知；同一进程 10 分钟内不重复通知；通知可在设置页关闭。
