# M5 刘海屏通知（Dynamic Island）

## 目标

进程告警（超高占用 / 长时间孤儿）以屏幕顶部中央的「灵动岛」卡片呈现：比 Windows 系统通知更显眼、可直接操作（查看 / 结束），且不破坏 M2 建立的杀前确认安全模型。

## 背景

- M4 已落地 Windows 原生 toast 通知（`useWatchdog` + tauri-plugin-notification）。
- 用户期望 WinIsland（https://github.com/Eatgrapes/WinIsland）式灵动岛体验。经评估**不集成 WinIsland**：GPLv3 传染、skia/winit 自绘栈与 Tauri/WebView 异构、体积与编译成本高、功能远超需求。
- 路线：Tauri 多窗口自建刘海窗口，复用现有快照数据链路与设计 token。

## 范围

- 新增 `island` 窗口：透明、无边框、置顶、跳过任务栏，主屏顶部居中
- watchdog 通知渠道分发：系统通知 / 刘海屏 / 两者
- 卡片交互：「查看」唤起主面板并选中进程；「结束」唤起主面板并弹出确认 Dialog
- 多告警排队展示；30 秒无操作自动收起
- 设置页「通知」区块增加形式选择

## 非目标

- 常驻迷你胶囊（实时 CPU 概览）——列入后续候选
- 媒体控制、音频可视化等 WinIsland 生态功能
- 多显示器分别显示（仅主屏）

## 验收标准

1. 构造高 CPU（阈值临时调到 50%，跑满任一进程 ≥ 两个采样周期），屏幕顶部中央展开灵动岛卡片，显示进程名 / PID / 指标
2. 「查看」唤起主面板、切到进程页并选中该进程；「结束」唤起主面板并弹出该进程的结束确认 Dialog，确认后才真正结束
3. 多个进程同时告警时排队展示并显示剩余条数；30 秒无操作自动收起
4. 设置页通知形式可切换 系统通知 / 刘海屏 / 两者，即时生效；「仅刘海屏」时不再弹 Windows toast
5. 刘海窗口不出现在任务栏与 Alt+Tab；主窗口关闭（托盘常驻）时刘海仍可弹出
6. `cargo test` / `cargo clippy -D warnings` / `npm run build` 全绿
