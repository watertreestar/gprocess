# M3 效率与体验

## 目标

把 M1/M2 的可用工具体验打磨到"常驻日常使用"级别：刷新更聪明、配置可调、长时运行稳定。

## 范围（按优先级，可裁剪）

**包含**

- 自动刷新策略：间隔可选（1s / 2s / 5s / 手动）、窗口失焦暂停、页面可见恢复
- 设置页：刷新间隔、孤儿运行时长阈值、默认过滤视图、主题切换（prism-light / console-dark）、是否显示系统进程
- 管理员提权入口：检测当前权限状态，提供"以管理员重启"操作（Windows `runas`）
- 排序/筛选增强：多列排序、自定义端口关注列表（如 3000/5173/8080 置顶）
- 性能：30 分钟连续运行稳定性验证与内存检查

**可选（视进度裁剪）**

- 系统托盘常驻 + 全局快捷键唤起
- 批量选中结束（仅限 safe 级别，逐条确认摘要）
- 快照 diff 高亮（新出现 / 已消失的进程短暂标记）

## 验收标准

1. 刷新间隔、阈值、主题等设置持久化（重启保留），且实时生效。
2. 窗口失焦时无后台轮询请求；恢复可见时立即刷新一次。
3. 普通权限下明确提示"部分端口/进程信息受限"，可一键以管理员重启。
4. 连续运行 30 分钟（2s 轮询）UI 无卡顿，内存无持续增长。
