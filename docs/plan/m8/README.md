# M8 文件句柄占用查找

## 目标

解决经典场景「文件被占用，无法删除/移动」：输入文件路径，查出哪些进程持有该文件的句柄，并能跳转查看进程详情或走确认流程结束进程。

## 范围

- 新增侧边栏第四个页面「句柄」（HandlesPage）
- 后端基于 Windows Restart Manager API 查询文件占用进程
- 结果列表展示：名称、PID、用户、状态、路径
- 每行提供「查看」（跳转进程页选中）和「结束…」（复用 KillDialog 确认流程）
- 不做：目录递归扫描、句柄强制解除（unlock）、批量查询

## 验收标准

- [ ] 用记事本打开某文件后，查询该路径能列出 notepad.exe 及其 PID
- [ ] 查询无占用的路径返回空列表，并显示「没有进程占用该文件」
- [ ] 「结束…」走现有 KillDialog 确认流程，结束后重新查询该文件不再被占用
- [ ] 「查看」跳转到进程页并选中对应进程
- [ ] cargo test / clippy / npm build 全绿

## 已知限制

- Restart Manager 对跨用户、高权限进程的可见性有限：查不到的占用会表现为空结果，而非报错
- 仅支持文件路径；目录路径行为未承诺
