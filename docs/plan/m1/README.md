# M1 端到端骨架

## 目标

打通"采集 → 展示 → 判断 → 结束进程"的最小完整链路：用户打开应用即可看到进程与端口占用，选中进程查看详情，并能安全地结束一个普通进程。

## 范围

**包含**

- Tauri 2 工程脚手架（React 19 + Vite + Tailwind 4 + Radix + Lucide）
- 应用壳：52/192px 侧栏、48px 全局顶栏、prism-light / console-dark 双主题 token
- Rust 后端：`snapshot()`（sysinfo + netstat2）、`kill_process(pid)`
- 进程页：数据行列表（虚拟滚动）、搜索、基础排序、右侧 300px 详情侧栏
- 端口页：端口 → PID → 进程 数据行，行内"查看进程"跳转
- 结束进程：确认 Dialog（浮层变体），展示命令行与影响端口；结构化错误提示（已退出 / 权限不足）

**不包含（M2/M3）**

- 孤儿判定、杀前安全分级、进程树、结束进程树
- 自动刷新配置、设置页、提权、托盘

## 验收标准

1. `npm run tauri dev` 启动后 2 秒内渲染完整进程列表与 LISTEN 端口列表。
2. 端口页任一行可回答"谁占了这个端口"：端口、PID、进程名、启动时间同屏可见。
3. 选中进程后详情侧栏展示完整命令行（mono，可复制）与其占用的端口。
4. 结束一个用户态普通进程成功；进程已退出 / 权限不足时给出明确的行内或通知提示。
5. 视觉通过 `workbench-design-system.md` 第 8 节复刻检查清单；两主题仅 token 差异。
